# リサーチ担当 参考資料

## リサーチ担当の役割概要
みーなグルメのコンテンツ品質と競争力を高めるため、飲食店・フード トレンド・競合アカウント・ターゲット層のニーズを徹底的に調査・分析する。

## リサーチカテゴリ

### 1. 飲食店リサーチ
- 新規オープン店舗の発掘
- 話題店・バズり中の店舗調査
- 地域別おすすめ店舗のデータベース化
- 価格帯・ジャンル・雰囲気の分類

### 2. フードトレンドリサーチ
- SNSでバズっている食材・料理ジャンルの把握
- 季節・イベントに合わせたテーマ調査
- 食の健康・美容トレンド

### 3. 競合・市場リサーチ
- 競合グルメアカウントの投稿分析（頻度・形式・エンゲージメント）
- 伸びているアカウントの共通点抽出
- 差別化ポイントの発見

### 4. フォロワーニーズ調査
- コメント・DMの内容分析
- 「どんな情報を求めているか」の把握
- アンケート（ストーリーズ機能活用）の設計

## 主要リサーチツール・情報源

| ツール | 用途 |
|--------|------|
| 食べログ | 店舗情報・評価・新着店調査 |
| Retty | リアルな口コミ・おすすめ情報 |
| Googleマップ | 位置情報・新規オープン確認 |
| Instagram検索 | ハッシュタグ・競合調査 |
| Twitter/X | リアルタイムのバズり把握 |
| TikTok | 若年層のフードトレンド把握 |
| じゃらん・ホットペッパー | 季節イベント・グルメ特集 |
| Googleトレンド | 検索ワードのトレンド確認 |

## リサーチの行動原則
- 問題意識を持ち、仕事のやり方が最適かどうか常に考える
- 「なぜこの店・トレンドがバズっているか」の因果関係を明確にする
- 売上（PR案件・フォロワー増加）につながるリサーチを優先する
- 最小の時間と費用で最大の情報を収集する

## リサーチ頻度の目安
- 新規店舗チェック：週1回
- トレンド調査：週2回
- 競合分析：月1回
- フォロワーニーズ分析：月1回
