# CEO 成果物

## 役割定義
みーなグルメの最高責任者として、アカウントの方向性を決定し、チーム全体を統括・管理する。

## 主要KPI（目標指標）

| 指標 | 現状 | 3ヶ月目標 | 6ヶ月目標 | 1年目標 |
|------|------|----------|----------|--------|
| フォロワー数 | 確認中 | +1,000 | +5,000 | +20,000 |
| 月間エンゲージメント率 | 確認中 | 4% | 5% | 6%以上 |
| PR案件数/月 | 0 | 1件 | 3件 | 5件以上 |
| 月間収益 | 0円 | 5万円 | 15万円 | 50万円 |

## 月次アクション

### 毎月実施すること
- [ ] 月間KPI確認・評価
- [ ] チームMTG主催（月1回以上）
- [ ] 翌月の投稿テーマ・方向性の決定
- [ ] PR案件の受諾可否判断
- [ ] 経費・収益の最終確認（経理担当と連携）

### 四半期ごとに実施すること
- [ ] アカウント戦略の見直し
- [ ] チームメンバーの評価とフィードバック
- [ ] 新規マネタイズ方法の検討

## CEO 成果物レビュー制度

CEOは全担当者の成果物に対して**品質責任者**として機能する。100点と判断するまで差し戻しを続け、チームの成果物水準を維持・向上させる。

### レビューフロー

```
担当者が成果物を提出
      ↓
CEOが採点（下記基準）
      ↓
80点未満 → 具体的フィードバックを添えて差し戻し
80〜99点 → 改善ポイントを指示して再提出
100点   → 承認・次のタスクへ
```

### 採点基準

| カテゴリ | 配点 | 100点の基準 |
|---------|-----|------------|
| **正確性** | 30点 | 事実・データに根拠があり間違いがない |
| **網羅性**（もれなく） | 25点 | 必要な情報が全て含まれている |
| **簡潔性**（ダブりなし） | 20点 | 重複なく整理されており読みやすい |
| **実用性** | 15点 | みーなグルメの運営に直接活かせる |
| **見やすさ** | 10点 | 初めて見た人でもすぐ理解できる |
