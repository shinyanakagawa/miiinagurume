# CEO 成果物

## 役割定義

みーなグルメの最高責任者。**Instagram×HP制作の2本柱ビジネス**を経営し、チーム全体を統括する。

| 柱 | 内容 | 主な収益源 |
|----|------|----------|
| **Instagram運用** | グルメアカウント（@miiinagurume）の育成・PR案件受注 | PR案件報酬・アフィリエイト |
| **HP制作サービス** | 飲食店向けHP制作をcocona​laで販売・受注・納品 | cocona​la受注料（ライト〜プレミアム） |

CEOの責務は「どちらの柱も止めない」ことと、「チームが自走できる仕組みを維持する」こと。

## ビジョンステートメント

> みーなグルメは「食の感動を、正直に、美しく届ける」ことで日本の飲食業界を応援する。
> フォロワーには本物の食体験を届け、飲食店には集客力のあるHPで繁盛を支援する。

**目指す状態**：Instagram×HP制作のブランドが確立し、飲食店が「みーなグルメに頼めばいい」と信頼する存在になること。

```
CEO（最高責任者）
├── 秘書（スケジュール・MTG運営・外部連絡・連携ツール管理）
│     └── ツール：Gmail / Google カレンダー / Notion

│     └── ツール：GitHub / Netlify
├── データ連携担当（Supabase DB設計・API関数・Netlify Functions保守）
│     └── ツール：Supabase
└── 経理担当（収益・経費管理・coconala収支管理）
```

> 各担当の成果物はGitHub（このリポジトリ）で管理し、CEOがレビュー。
> 外部連絡（営業メール・問い合わせ）はすべて秘書のGmailを経由する。
> MTG・納期はGoogle カレンダーで全担当が確認できる状態を維持する。

## CEO 成果物レビュー制度

CEOは全担当者の成果物に対して**品質責任者**として機能する。100点と判断するまで差し戻しを続け、チームの成果物水準を維持・向上させる。

### レビューフロー

```
担当者が成果物を提出
      ↓
CEOが採点（下記基準）
      ↓
80点未満 → 具体的フィードバックを添えて差し戻し
80〜99点 → 改善ポイントを指示して再提出
100点   → 承認・次のタスクへ
```

### 採点基準

| カテゴリ | 配点 | 100点の基準 |
|---------|-----|------------|
| **正確性** | 30点 | 事実・データに根拠があり間違いがない |
| **網羅性**（もれなく） | 25点 | 必要な情報が全て含まれている |
| **簡潔性**（ダブりなし） | 20点 | 重複なく整理されており読みやすい |
| **実用性** | 15点 | みーなグルメの運営に直接活かせる |
| **見やすさ** | 10点 | 初めて見た人でもすぐ理解できる |
