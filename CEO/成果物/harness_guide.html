Claude Code

Harness の仕組み

Claude Code が動くたびに、自動でコマンドを走らせる仕組みです。

Harness とは

Claude Code がツールを呼び出したり、作業を終えたりする 特定のタイミングで、 あらかじめ設定したシェルコマンドを 自動実行する仕組みです。
設定は settings.json の hooks セクションに記述します。

実行フロー

ユーザーが指示
→
PreToolUse hook
→
ツール実行
→
PostToolUse hook
→
Claude 返答
→
Stop hook

イベントの種類

PreToolUse

ツール呼び出しの
直前に発火

PostToolUse

ツール呼び出しの
直後に発火

Stop

Claude が回答を
完了したときに発火

SubagentStop

サブエージェントが
完了したときに発火

Notification

Claude が
通知を送るときに発火

設定例

settings.json .claude/settings.json 
// Stop: 作業完了時に通知を送る
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "echo '✅ Claude が作業を完了しました'"
          }
        ]
      }
    ],

    // PreToolUse: Bash 実行前にログを残す
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "echo 'Bash を実行しようとしています'"
          }
        ]
      }
    ]
  }
}

実用例

💬

LINE / Slack 通知

Stop

作業完了時に LINE Notify や Slack webhook で通知を送る

🛡️

危険コマンドをブロック

PreToolUse → Bash

rm -rf など危険なコマンドを検知して実行前に止める

✨

自動フォーマット

PostToolUse → Edit

ファイル変更後に Prettier や ESLint を自動実行する

💡
設定を追加するには
Claude Code で /update-config と入力するとGUI付きで hooks を設定できます。 LINE 通知の組み込みや特定ツールのブロックなど、具体的なユースケースに合わせて設定できます。
