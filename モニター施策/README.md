## 決定事項

### 1. 出品は1つだけ（モニター専用の別出品は作らない）
- レビュー・販売実績は**出品ごと**に付くため、本命の出品1つに集約する
- モニター価格で開始し、件数に応じて同じ出品の価格を引き上げる
- DM営業で獲得した店舗にも同じ出品URLから購入してもらう

### 2. 価格の段階

| 段階 | 件数 | 価格 | タイトル |
|------|------|------|---------|
| モニター | 1〜3件目 | 10,000円 | 「【先着3店舗モニター価格】」を付ける |
| 実績づくり | 4〜10件目 | 20,000円 | 「モニター」表記を外す |
| 通常 | 11件目〜 | 30,000円〜（ライト／スタンダード50,000円／プレミアム90,000円） | 通常タイトル |

- 価格は1万円単位にする（ココナラの価格刻み、およびWebサイト制作カテゴリの最低価格1万円との報道に合わせるため。出品画面で要確認）
- 公開費用（HP生成アプリの月額1,000円相当）は**制作費に1年分込み**とし、出品文では「サーバー代など追加費用なし（1年間）」と表記する
  - ココナラで出会った購入者からココナラ外で月額を受け取るのは直接取引として規約違反になる恐れがあるため、別途の月額請求はしない
  - 2年目以降の更新もココナラで購入いただく形にする
  - 実費：全店舗でNetlify・Supabase・Cloudflareの無料枠とドメイン1つ（年1,500円前後）を共有するため、1店舗増えるごとの追加費用はほぼ0円

### 3. モニター条件
- ココナラ経由で購入いただく
- 制作事例としての掲載を許可いただく
- みーなグルメInstagramでの紹介を許可いただく
- レビューは**条件にしない**（「ご協力のお願い」に留める。★の数の指定は絶対にしない）
  - 評価と引き換えの値引きはココナラのガイドライン違反になる恐れがあるため。出品前にココナラの「ガイドライン」評価関連の項目を確認すること

### 4. 営業方式：「先に食べて投稿 → 試作HPを見せる」
1. 対象を選ぶ（開業1年以内／HPなし or Instagramのみ／個人店／中目黒・恵比寿・池尻大橋・渋谷・表参道）
2. 来店し、@miiinagurume で紹介投稿（無償）
3. Instagram DMで連絡
4. HP生成アプリで試作HPを作り、非公開プレビューURLを送る
   - 許可前は公開しない。店舗の写真は使わずサンプル画像で作成
5. 興味があればココナラの出品から購入
6. 納品 → レビューのお願い → 制作事例としてInstagram投稿

### 5. 数値目標
- 前提：DM返信率30%、返信からの成約10%（仮定。実績で更新する）
- モニター3件に必要な接触数：約30店
- ペース：週10店に接触 → 約1ヶ月でモニター3枠を埋める
- 営業先リストを現在の6件から30件へ拡充（リサーチ担当）
