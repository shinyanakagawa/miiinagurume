# DM・メッセージ テンプレート

> 送信前に店名・料理名・URLを必ず差し替える。
> 試作HPは非公開プレビューのみ。店舗の写真は許可を得るまで使わない（サンプル画像で作成）。
> レビューは「お願い」に留め、★の数の指定・値引きとの引き換えは絶対にしない。

## パターン1：紹介投稿済みのお店（基本形）

```
○○ ご担当者さま

突然のご連絡失礼いたします。
先日お伺いし、Instagramで「○○（料理名）」をご紹介させていただいた、みーなグルメです。
（投稿URL：）

料理もお店の雰囲気も本当に素敵だったので、勝手ながら、お店のホームページを試作してみました。
▶ 試作ページ（非公開）：

現在、飲食店さま向けのHP制作を、先着3店舗限定のモニター価格（9,800円／通常29,800円）で承っています。
公開費用も最初の3ヶ月は無料です。

もしご興味があれば、お気軽にご返信ください。
もちろん、ご興味がなければこのメッセージは流していただいて大丈夫です。

みーなグルメ
```

```
○○ ご担当者さま

はじめまして。Instagramで飲食店を紹介している、みーなグルメ（@miiinagurume）です。
○○さまのInstagramを拝見し、○○（料理名・雰囲気など具体的に）にとても惹かれました。

ホームページがまだないようでしたので、勝手ながら試作してみました。
▶ 試作ページ（非公開）：

現在、先着3店舗限定のモニター価格（9,800円／通常29,800円）でHP制作を承っています。
近いうちにお店にも伺わせていただきたいと思っております。

ご興味があれば、お気軽にご返信ください。

みーなグルメ
```

## パターン3：返信があったとき（ココナラへの案内）

```
ご返信ありがとうございます！

ご依頼はココナラから承っております。下記のページからご購入いただけます。
▶ （ココナラ出品URL）

ココナラのアカウント登録（無料）が必要になります。
ご購入後、営業時間やメニューなどを簡単にお伺いし、7日以内を目安に仕上げます。
試作ページで気になる点があれば、その際にお気軽にお申し付けください。
```

## パターン4：納品時（ココナラのメッセージ）

```
このたびはご依頼いただき、誠にありがとうございました。
ホームページを公開いたしました。
▶ 公開URL：

公開費用は最初の3ヶ月無料、以降は月額1,000円です。
内容の変更などがあれば、いつでもご連絡ください。

もしよろしければ、今回のお取引について評価・レビューをいただけますと、今後の励みになります。
お気持ちのままにご記入いただければ幸いです。

また、モニターの条件としてお伝えしておりました、制作事例への掲載とInstagramでのご紹介を、近日中に進めさせていただきます。
今後ともどうぞよろしくお願いいたします。
```

## フォローアップ（返信がない場合）
