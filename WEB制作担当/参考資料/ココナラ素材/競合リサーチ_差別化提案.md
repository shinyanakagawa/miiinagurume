# ココナラ「HP作成」競合リサーチ・差別化提案

## 1. 市場・価格相場（リサーチ結果）

| 規模 | 相場 | 補足 |
|------|------|------|
| 小規模HP（1〜5ページ程度） | 5万〜10万円 | 最安は2万円台の出品もある |
| LP（ランディングページ） | 5万〜40万円 | デザイン品質で大きく変動 |
| ECサイト | 15万〜30万円 | 機能追加で上振れ |
| 制作会社に依頼する場合 | 30万〜100万円 | ココナラは圧倒的に低価格帯 |

### オプション料金の相場
- SEO対策：+1万〜3万円
- 予約・問い合わせフォーム：+5千〜2万円
- ブログ/スライダー/地図埋め込み/SNS連携：各+5千〜2万円

### 納期
- 制作自体は1〜2週間が多いが、**写真撮影・文章準備などの素材集めで1ヶ月以上かかるケースが多い**（ボトルネックになりやすい）

---

## 2. 競合がよく使う差別化要素

- **デモサイト・ポートフォリオの提示**：クオリティとデザインセンスを事前に見せる
- **特典付与**：WordPress操作マニュアルなど「公開後に困らない」資料の同梱
- **関連サービスとのセット販売**：物撮り、商品ページ制作、SNS広告運用コンサルなど

→ 逆に言うと、**多くの出品者は「素材（写真・文章）はお客様側で用意してください」前提**であり、ここが飲食店オーナーにとって最大のハードルになっている。

---

## 3. 自チームの強み（差別化ポイント）

| 強み | 内容 |
|------|------|
| ① グルメアカウント運営者が直接作成 | 制作者目線だけでなく「集客につながる導線・写真の見せ方」を実運用知見から設計できる |
| ② 業種別サンプルが既に5種類完成 | カフェ/ビストロ/居酒屋/定食屋/高級店 それぞれの雰囲気に合わせたテンプレートを即提示でき、競合の「デモ1種類のみ」より説得力が高い |
| ③ 写真込みで対応可能 | 店舗写真が未整備でも、AI生成画像（nanobanana）を使った雰囲気写真で先行公開→後から実写へ差し替え可能。素材待ちによる納期遅延を回避できる |
| ④ 予約に繋がる導線設計 | 「予約ボタン・SNS誘導・地図」をInstagram運用と連動させた構成をテンプレートに標準装備 |
| ⑤ 公開後の更新サポート | Supabase連携のHP生成アプリにより、画像・文章をオーナー自身で簡単更新できる（WordPress知識不要） |
