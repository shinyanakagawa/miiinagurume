# データ連携担当 参考資料

## Supabase プロジェクト概要

- **プロジェクト名**：みーなグルメ HP生成アプリ
- **管理画面**：supabase.com（要ログイン）
- **ローカル設定ファイル**：プロジェクトルート `/supabase/` フォルダ

## 主要ドキュメント

| 資料 | 場所 |
|------|------|
| Supabaseローカル設定 | `miiinagurume/supabase/` |
| HP生成アプリのAPIクライアント | `miiinagurume/グルメHP作成アプリ/js/` |

## Netlify Functions

- 予約フォーム送信時にLINE通知・Resendメール通知を送る関数が実装済み
- デバッグはNetlify管理画面のFunctionsログから確認する

## 行動原則

- スキーマ変更は必ずマイグレーションファイルで管理する
- RLSポリシーは変更前後でセキュリティを手動確認する
- APIキー・シークレットはリポジトリにコミットしない（.envまたはNetlify環境変数で管理）
